# MACTBA

Landing page estática para servicios de montaje industrial, izaje y trabajos especializados.

## Vista previa local

Las imágenes se cargan desde `images/`. Para mantener esa ruta al usar un servidor local, inicia el servidor desde el directorio `mactba`:

```bash
python3 -m http.server 8000
```

Luego abre `http://localhost:8000/webpage/`. También puedes abrir `index.html` directamente en el navegador.

## Contenido

- `index.html`: estructura, secciones y galería.
- `styles.css`: diseño adaptable a escritorio y móvil.
- `app.js`: menú móvil y visor de imágenes.
- `favicon.svg`: ícono de la página, que se diseña a pedido del cliente para mostrar una imagen corporativa.
- `images/`: imágenes presentes en la página.

La sección de contacto no incluye teléfono ni correo porque esos datos se actualizan en la página real, esto es solamente una muestra.
